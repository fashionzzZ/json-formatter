# JSON Formatter Chrome Extension - Design Specification

**日期**: 2026-06-05
**项目**: JSON格式化Chrome浏览器插件

---

## 项目概述

### 目标
开发一个面向开发人员的Chrome浏览器插件，用于快速格式化、查看和编辑JSON数据，提升API调试和数据分析效率。

### 核心功能
- JSON格式化与美化（预处理去除换行符）
- 节点折叠/展开
- JSON压缩与复制
- 语法高亮（自动跟随系统主题）
- JSON验证与错误提示
- JSON编辑与导出
- 右键菜单快速格式化选中文本

---

## 架构设计

### 整体架构
采用标准的Chrome Extension Manifest V3架构：

**弹窗界面 (Popup)**
- 主界面，用户点击插件图标后打开
- 提供JSON输入区、格式化按钮、工具栏
- 集成JSON编辑器展示格式化结果

**后台服务 (Background Service Worker)**
- 处理右键菜单的注册和响应
- 管理与content script的通信
- 不持久化数据，每次会话独立

**内容脚本 (Content Script)**
- 注入到网页中，用于提取选中的JSON文本
- 当用户通过右键菜单触发时，将选中的JSON文本发送到后台处理

**右键菜单 (Context Menu)**
- 注册为浏览器上下文菜单项："格式化选中的JSON"
- 快捷入口，提升开发效率

### 数据流
用户输入 → 预处理（去除换行符） → 格式化处理 → JSON验证 → 结果展示

全程在前端完成，无需后端服务。

## 核心功能详细设计

### 1. JSON输入与预处理模块

**输入区**
- 大文本框，支持粘贴大量JSON数据
- 自动检测粘贴操作，提供快捷入口

**预处理函数**
- 去除输入文本中的所有换行符和多余空格
- **实现原理**：在标准JSON中，字符串值内的换行符以转义序列 `\n` 表示，而非字面换行符。因此可以安全地去除所有字面换行符，不会影响JSON数据内容
- 去除前后空格，确保数据整洁

**格式化按钮**
- 点击后触发预处理+格式化流程
- 显示处理状态（加载中/成功/错误）

### 2. JSON编辑器模块（基于jsoneditor库）

**展示模式**
- 树模式：可视化树状结构，支持节点折叠展开
- 代码模式：文本编辑，语法高亮
- 用户可在两种模式间切换

**节点折叠**
- 点击节点左侧箭头图标展开/折叠
- 箭头图标：▶（展开），▼（折叠）
- 支持全展开/全折叠快捷按钮

**语法高亮**
- jsoneditor自带语法高亮（基于ace editor）
- 自动跟随系统主题（深色/浅色）
- 高亮区分：键名、字符串、数字、布尔值、null

### 3. 工具栏功能

**压缩按钮**
- 将当前JSON压缩为紧凑格式（去除所有空格和换行）
- 在编辑器中显示压缩结果
- 独立按钮，清晰明了

**复制按钮**
- 复制当前显示的JSON到剪贴板
- 根据当前模式复制（树模式复制格式化版，代码模式复制当前文本）
- 提供复制成功提示（toast，1.5秒自动消失）

**保存按钮**
- 保存修改后的JSON为文件（下载）
- 文件名默认：formatted-json.json

## 其他功能详细设计

### 1. JSON验证与错误处理

**语法检测**
- 在格式化过程中自动进行JSON.parse验证
- 如果JSON无效，显示错误提示

**错误展示**
- 在编辑器上方显示醒目的错误提示框
- 红色边框和图标标识错误状态
- 错误提示包含：错误位置、错误类型、简要说明
- 提供"查看详情"链接，展开完整错误信息

**修复建议**
- 对于常见错误（如缺少引号、尾随逗号等）提供修复提示
- 不自动修复，让用户决定是否修改

### 2. JSON编辑功能

**编辑方式**
- 在代码模式下直接编辑文本
- 在树模式下可编辑节点值（文本框输入）
- 添加/删除节点功能

**实时验证**
- 编辑时实时检测语法有效性
- 无效修改显示警告，但不阻止用户操作

**导出功能**
- 保存修改后的JSON为文件（下载）
- 复制修改后的JSON到剪贴板

### 3. 右键菜单功能（简化版）

**菜单项注册**
- 仅注册一个菜单项："格式化选中的JSON"
- 当用户在网页上选中文本时可用

**触发流程**
- 用户在网页上选中JSON文本
- 右键选择"格式化选中的JSON"
- Content script提取选中的文本
- 发送到后台，后台打开popup并传递数据
- Popup自动填充并格式化接收的JSON

## UI/UX设计细节

### 弹窗界面布局

**整体尺寸**
- 弹窗宽度：800px（足够展示复杂JSON结构）
- 弹窗高度：600px（可滚动，适应不同数据量）

**区域划分**
- 顶部：工具栏（格式化按钮、压缩按钮、复制按钮、保存按钮）
- 中部左侧：输入区（文本框，占30%宽度）
- 中部右侧：JSON编辑器展示区（占70%宽度）
- 底部：状态栏（显示JSON大小、验证状态等）

### 主题切换设计

**自动跟随系统**
- 使用 `matchMedia('(prefers-color-scheme: dark)')` 检测系统主题
- 系统切换主题时，插件自动更新
- 实时监听主题变化，无需手动刷新

**配色方案**
- 深色主题：深灰背景、白色文字、高对比度语法高亮
- 浅色主题：白色背景、黑色文字、柔和的语法高亮配色
- JSONEditor自带主题支持，直接使用其深色/浅色主题

### 交互细节

**格式化按钮**
- 绿色主色调，醒目易识别
- 点击后显示加载状态（旋转图标）
- 成功后显示绿色勾号，失败显示红色叉号

**节点折叠图标**
- 使用标准箭头图标（▶展开，▼折叠）
- 箭头颜色与主题协调
- hover时箭头高亮，提示可点击

**复制操作**
- 复制成功后显示toast提示（"已复制到剪贴板"）
- 提示自动消失（1.5秒）
- 使用绿色背景，与成功状态一致

**错误提示**
- 红色边框和背景（柔和的红色，不刺眼）
- 错误图标（⚠）醒目但不突兀
- 文字清晰易读，包含具体错误信息

## 技术实现细节

### 依赖库选型

**核心编辑器**
- jsoneditor 9.x（最新稳定版）
- 包含树模式、代码模式、编辑、验证、搜索等完整功能
- 支持深色/浅色主题切换

**其他依赖**
- 无需额外库，jsoneditor已内置所有必需功能
- 语法高亮由jsoneditor自带的ace editor提供

### Chrome Extension文件结构

```
json-formatter-extension/
├── manifest.json
├── popup.html
├── popup.css
├── popup.js
├── background.js
├── content.js
├── icons/
│   ├── icon16.png
│   ├── icon48.png
│   └── icon128.png
└── lib/
    └── jsoneditor.min.js
```

**manifest.json配置**
- 使用Manifest V3规范
- 声明permissions: contextMenus, clipboardWrite, clipboardRead
- 声明background service worker
- 注册popup页面和content script

### 性能与兼容性考虑

**性能优化**
- JSON数据量限制：建议不超过5MB（避免超大JSON导致渲染卡顿）
- 对于超大JSON，显示警告提示，建议用户分段处理
- 使用虚拟滚动技术处理长列表（jsoneditor已内置）

**浏览器兼容**
- Chrome 88+（Manifest V3最低版本要求）
- 不支持其他浏览器（专注Chrome插件）
